# Changelog

All notable changes to Eliejesresce K2 Themes are documented here.

## [3.0.0] - 2026-07-11

### Added

- K2 Coherence: balanced and technical.
- K2 Vacuum: deep, quiet and near-black.
- K2 Dim: expressive pastel colors over an indigo-plum background.
- K2 Endurance: high contrast for long development sessions.
- Syntax coverage for Python, Qiskit, TypeScript, JavaScript, Java, Rust, C,
  HTML, Django templates, CSS, JSON, YAML and Markdown.
- Workbench colors for terminals, diagnostics, diffs, debugging, testing,
  notebooks, notifications, menus, command palettes and peek views.
- Deterministic theme generation.
- Semantic and component overrides per variant.
- Contrast contracts and generated-theme synchronization checks.

### Changed

- Replaced manually maintained themes with a shared token architecture.
