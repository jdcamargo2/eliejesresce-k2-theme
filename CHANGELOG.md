# Changelog

## [3.0.0] - 2026-10-28

### Added

- Six themes: Coherence, Vacuum, Dim, Endurance, Ferro and the light Ash variant.
- Workbench colors for terminals, diagnostics, diffs, debugging, testing, notebooks, notifications, menus and other surfaces.
- Automated tests, contrast contracts, generated-theme synchronization and difference reports, and a CI workflow.

### Changed

- Generate themes from a shared token architecture.
- Share Ferro syntax colors across the five dark variants while retaining their backgrounds; adapt the same syntax roles for Ash.
- Update TextMate and semantic rules and development fixtures.
