# Eliejesresce K2

Eliejesresce K2 is a semantic theme system for Visual Studio Code.

Its purpose is not merely to color source code, but to reveal structure, reduce visual noise and communicate editor state through a consistent visual language.

> K2 does not color code. It reveals its structure.

## Themes

### K2 Coherence

The primary K2 theme, designed for daily engineering work and long development sessions.

K2 Vacuum and K2 Laboratory are under development.
